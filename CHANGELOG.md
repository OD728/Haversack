# Haversack changelog

## 1.0.4

- New optional category "Cooking & Fishing": ingredients, fish, spices, Cooking and Fishing
  recipe books, fishing poles and lures in one section. Off by default; turn it on under
  ESC > Options > AddOns > Haversack.
- Haversack now has its own page in the game options (English and German).

## 1.0.3

- Camping features that need a main profession (Spinning Wheel, Loom, Anvil, Tanning
  Rack and so on) now go into that profession's category instead of Everything Else.

## 1.0.2

- Everything Else is now sorted by rarity first: epic, rare, uncommon, common, then poor.

## 1.0.1

- Free slots now count only your normal bags. The soul bag and other special bags
  (herb, enchanting, ammo...) only hold one kind of item, so their empty slots no
  longer show up as free space.

## 1.0

First release.

- All your bags in one window, sorted into a few categories: Quest Items, Food & Water,
  one category for each main profession you have learned (Alchemy, Blacksmithing,
  Enchanting, Engineering, Herbalism, Leatherworking, Mining, Skinning, Tailoring)
  and Everything Else.
- Square slots with a thin frame in the item's rarity color (yellow for quest items)
  and a soft shadow.
- Item level on weapons and armor in the rarity color.
- Gold and, for warlocks, your Soul Shard count at the bottom. Shards stay out of the
  grid; the soul bag is part of the window.
- All empty slots shown as one slot with the free count.
- Search box and a button for the game's own bag sort.
- Uses the game's own bag slots, so using, moving and selling items work as usual,
  also in combat.
- B opens all bags (it uses the game's "Open All Bags"). Your key bindings are not changed.
- A clean, dark window that fits the game's own UI.
- English and German.
